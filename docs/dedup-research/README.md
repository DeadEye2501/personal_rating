# Разбор дедупликации игр, 02.08.2026

Сохранено не ради решения — решение принято и записано в
`docs/specs/2026-08-02-game-sources.md`: **автоматической склейки не будет,
дубли убирает человек, а приложение помнит удалённое.**

Сохранено ради данных. Разметка 913 пар глазами — работа на час, и если однажды
захочется вернуться к автоматической склейке, начинать заново незачем.

## Что здесь лежит

| файл | что это |
|---|---|
| `pairs.json` | 226 запросов по известным названиям, до трёх строк от каждого из трёх источников со всеми полями, которые источник отдаёт даром |
| `truth.py` | разметка «одна игра / разные игры» по 913 парам-кандидатам; верных пар **411** |
| `norm.py` | приведение названий: знаки до `NFKC`, римские в арабские, снятие хвоста издания |
| `common.py` | чтение данных и разбор на пары |
| `dedup-analysis.md` | отчёт разбора со всеми прогонами и таблицами |

Пробы правил: `evaluate.py` (широкое правило), `try_colon.py` (резать по
двоеточию), `try_prefix.py` и `try_digit.py` (префикс со сторожами),
`try_strict.py`, `try_strict2.py`, `try_safe.py` (поиск признака без ошибок).

Сбор: `collect_pairs.py` собирает `pairs.json`, `add_ru_titles.py` дописывает
русские названия GOG, `refetch_og.py` пересобирает половину old-games.

## Как запускать

Из этой папки, интерпретатором проекта. `refetch_og.py` требует
`beautifulsoup4` — в `Pipfile` его пока нет.

## Чем это кончилось

| правило | верных | ложных |
|---|---|---|
| **свод без ошибок** (GOG↔Steam буква в букву, GOG↔old-games ключ + год ±1) | **179** | **0** |
| широкое: набор ключей со снятием изданий | 363 | 37 |
| Левенштейн ≥ 0.85 | 342 | 249 |
| резать название по двоеточию | 347 | 239 |
| префикс + сторож «источник не возражает» | 390 | 213 |
| префикс с числом + тот же сторож | 375 | 55 |
| разработчик или издатель как ключ | — | 171 |

**Оговорка к числам.** Разметка делалась на данных до починки сбора: у
old-games сперва не собирались год, платформа и издатель — разбор ячеек
регулярками обрывался на таблице, вложенной внутрь строки. Метки привязаны к
номерам строк и не поехали, но кандидатов теперь может быть больше, чем
размечено: настоящее число верных пар может оказаться выше 411.
