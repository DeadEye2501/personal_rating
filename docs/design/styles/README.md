# Стили

Подключать в таком порядке:

```html
<link rel="stylesheet" href="styles/tokens.css">
<link rel="stylesheet" href="styles/base.css">
<link rel="stylesheet" href="styles/neon.css">
```

| Файл | Содержимое |
|---|---|
| `tokens.css` | Переменные: фон, акцент, красный, стекло, шкала оценок, текст, радиусы, типографика |
| `base.css` | Сброс, тело документа, фокус, иконки, `prefers-reduced-motion` |
| `neon.css` | Неоновая кромка: приём целиком, одним классом |

Стили экранов живут в блоке `<style>` внутри `index.html` — макет одностраничный,
разносить их по файлам смысла нет. В отдельный файл выносится только то, что
применяется больше чем в одном месте и ни к какому экрану не привязано.

## Неоновая кромка

Класс `neon` даёт полосу по верхней кромке, гаснущую к краям, гало под ней и
свечение текста. Цвет берётся из `--neon`, высота гало — из `--halo-h`; и то и
другое задаёт тот, кто вешает класс.

Сейчас класс носит нижняя плашка сообщений, и горит она постоянно.

## Шкала оценок

Единая нотация: цвет закреплён за значением и одинаков везде — в фильтре по
оценке, на звёздах в карточках, в столбцах гистограммы. Красный на единице,
синий на десятке.

Имя переменной собирается в JS строкой — `var(--score-${n})`, — поэтому в CSS
литеральных обращений к `--score-3` и подобным нет. Любой автоматический поиск
неиспользуемого объявит их мёртвыми; они живые.

## Переменные, которые ставит JS

В CSS они встречаются только как `var(...)`, объявления у них нет:

| Переменная | Где ставится | Зачем |
|---|---|---|
| `--content-w` | замер шапки | ширина ленты и гистограммы |
| `--side-w`, `--tools-w` | замер шапки | ширина блоков в разных раскладках |
| `--score` | инлайн у строки | цвет звёзд, ярлыка и столбца |
| `--h`, `--i` | инлайн у столбца | высота и задержка анимации |
| `--fill` | инлайн у звезды | доля закраски дробной звезды |

## Заливка иконок

Правило в `base.css`: иконка внутри элемента с классом `is-active` или `is-on`
переключается на закрашенный вариант через ось `FILL` шрифта Material Symbols.
Контур в покое, заливка во включённом состоянии.

## Атрибут hidden

`[hidden]{ display:none !important }` в `base.css` — не косметика. На нём держатся
модалки и полоса прокрутки: JS переключает именно атрибут, а у этих элементов в
классах задан свой `display`. Без `!important` они были бы видны всегда.
