# Ревью планов

Ход работ по вычитке шести планов реализации. По файлу на итерацию: чем шли,
что нашли, что починили, что оставили и почему.

Кода в проекте нет — предмет ревью это `docs/plans/*.md`, а вместе с ними спеки и
`CLAUDE.md`, куда правки утекают следом.

## Как устроен цикл

Пачка агентов с разными линзами → находки → разбор по степени важности →
правки по critical и important → отчёт → коммит → следующая пачка по уже
исправленным планам. Повторяется, пока полный заход не вернёт ни одного
critical и important.

## Линзы

| Линза | Что смотрит |
|---|---|
| Манифест: слои и потоки | клиент не знает про SQLAlchemy и httpx, бэкенд не знает про Qt; в главном потоке нет сети и диска; постер байтами; пул ленты |
| Манифест: модульность и SOLID | одна ответственность на модуль, общее вынесено сразу, седьмой источник не трогает существующие файлы; и обратное — абстракция без второй реализации |
| Манифест: данные и обещания | частичной карточки в базе не бывает, офлайн держится, теги только от человека, привязка заполняет только пустое, тёзки различаются жестом |
| Манифест: вид и чистовик | сверка с макетом, ось `FILL`, переход 0.16 с, хлам в комментариях, лишнее в чистовике |
| Модульность фронта | все стили в библиотеке, все общие элементы в своей библиотеке, нет повторяющихся кусков, фронт ничего не знает о `docs/design/` |
| Сборка и прогон | код по плану пишется целиком в изолированном дереве и запускается; по агенту на план |
| Скептик | исходит из того, что всё сломано, и обязан это доказать |
| Связность | стыки планов 1→6: имена, подписи, типы, пути к файлам |
| Качество тестов | тесты, которые не могут упасть, и тесты, требующие неверной реализации |

## Степени

- **critical** — по плану нельзя написать работающий код; либо написанный по
  нему код молча портит данные; либо решение из манифеста нарушено так, что
  переделывать придётся много.
- **important** — реализуемо, но расходится с манифестом, спекой или макетом;
  либо тест не ловит то, ради чего написан; либо дублируется код, который
  манифест велит выносить.
- **minor** — косметика, опечатка, вкусовое. Чиню, когда попадается под руку,
  но итерации из-за них не повторяю.

Цикл останавливается, когда полный заход не даёт ни critical, ни important.
