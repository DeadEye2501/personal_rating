## Проверено живым запросом 31.07.2026: GOG сломан

Рекомендация рецензента по спекам оказалась не мелочью. Проверено на живом API
собственным клиентом проекта:

```
поиск "The Witcher 2": Found, нашлось 27
   1640424747 | Ведьмак 3: Дикая Охота
   1207658930 | Ведьмак 2: Убийцы королей
карточка по 1640424747: Refusal — каталог не вернул 1640424747
карточка по 1960488876: Refusal — каталог не вернул 1960488876
```

`GogClient.card` повторяет запрос к каталогу, подставляя числовой идентификатор
в параметр `query`, а **каталог по числу не находит ничего**: `productCount: 0`.
Проверены и другие формы — `productIds` и `query=id:…` каталог молча
игнорирует, возвращая случайную выдачу. Работает только текстовый запрос.

Следствие: **добавить игру из GOG через поиск нельзя вовсе.** Путь вставленной
ссылки цел — `resolve_slug` спрашивает каталог словами слага, а это каталог
понимает.

Ни 905 тестов, ни 436 мутаций этого поймать не могли: записанная фикстура
отвечает на запрос по названию, и клиент на ней ведёт себя правильно.

Товарный API `api.gog.com/products/{id}` по числу отвечает и отдаёт `slug`, но
ни жанров, ни оценки в нём нет — заменить им каталог нельзя.

## Что править в боевом коде

Список короткий, и это главный итог: **436 мутаций не нашли в бэкенде ни одной
ошибки поведения.** Всё, что ниже, — либо нарушение записанного правила, либо
объявление без потребителя.

1. **MDBList: отрицательный факт по неразобранному телу.**
   `sources/ratings/mdblist/client.py:63` отдаёт `Missing()` на голом 404.
   Правило проекта — писать отрицательный факт только по разобранному телу;
   это единственный источник из шести, который его нарушает, и именно тот, у кого
   чужой периметр пойман живьём. Сосед по файлу (`_denied`) тело уже разбирает.
2. **Объявления без сегодняшнего потребителя** (правило 8): `Loader.__init__`
   принимает `clock` и кладёт в `self._clock`, который не читает никто;
   `is_answer` выведен в `__all__` и зовётся только собственным тестом.
3. **Повторы, закрываемые одним объявлением в существующем модуле:**
   «взвести предохранитель и отказать тем же сроком» — шесть мест, дом готов
   (`sources/errors.py` рядом с `refuse_code`); четыре дословные строки «спросить
   магазин» у Steam и GOG — дом готов (`sources/undocumented.py`).

## Что править в тестах

1. **Сторож границы слоёв ослеп** — `tests/backend/test_layers.py:13` запрещает
   бэкенду `PySide6` и ничего не знает про `webview` и `pythonnet`. Это
   единственная машинная проверка правила 10, и чинить её надо **до** первой
   строки нового клиента.
2. **Сборка не наблюдается** — `loader`, `series`, `genres`, `enricher`, `linker`,
   `search`, `feed` не трогает ни один тест; `loader=None` и постерный сервис без
   клиентов оставляют набор зелёным. Место, которое дважды оказывалось самым
   опасным в проекте.
3. **Жанры и теги Steam не сверяются с записанным ответом** — сторожится форма
   метки, а не её номер. У TMDB и GOG сверка есть.
4. **Неизменяемость типов границы** сторожит список из шести, объявлений — 23.
5. **Три дыры сервисного слоя:** тип содержимого при «перезаписать»; `kind` на
   пути к оценочному клиенту (все сериалы получали бы «нет» и пустую строку на
   месяц); адрес обложки при привязке — правило «что человек написал, остаётся
   его» для него не сторожится.
6. **Три дыры хранилища:** `_has_item` с `>=` вместо `==`; откат справочника
   жанров частичным `downgrade`; пустые байты в `PosterStore.has`.
7. **Имя клиента источника не наблюдается ничем** — оно уходит в отказ и называет
   источник; разойдись с литералом, человек пойдёт править не тот ключ.
8. **Два теста границы слоёв сегодня не удостоверяют ничего** — пакет `client/`
   это один пустой `__init__.py`.
9. **Восемь докстрингов утверждают неправду** (подробности в отчётах по манифесту
   и по набору тестов).

## Что требует решения пользователя

1. **Строка `PYTHONDONTWRITEBYTECODE=1` в `.env` ничего не делает.**
   `pipenv/environments.py:14` ставит эту переменную сам, на уровне модуля, без
   условий — так было всегда. Вне pipenv `.env` не читается вовсе, поэтому будущий
   `.exe` снова начнёт раскладывать кэш. Либо убрать как пустую, либо заменить
   настоящим средством в новой точке входа.
2. **`.env` не читает ни одна строка своего кода** — `python-dotenv` остался в
   зависимостях без потребителя после отката клиента. Вернётся вместе с точкой
   входа.
3. **Спеки обещают то, что планы отменили:** доля положительных отзывов Steam
   (`RatingSource.STEAM` не производится нигде); откат по квоте у зеркал
   Кинопоиска — константа 6 ч вместо запроса остатка; порция внешнего поиска у игр
   вдвое больше объявленных двадцати. Решать: править спеки или доделывать код.
4. **`alembic upgrade head` не записан в `CLAUDE.md`** — только в `docs/plans/` и
   `docs/reviews/`, а `docs/` объявлена одноразовой.
5. **`.gitignore` исключает `.claude/` целиком** — в клон не попадают ни хуки
   (семь правил манифеста из шестнадцати), ни `tools/module_map.py`, которым
   `--check` сторожит карты. Скилл лежит в отдельном архиве, так что это может
   быть намеренно.
6. **Один живой запрос к каталогу GOG по числовому id** — если поиск по числу не
   работает, добавить игру из GOG нельзя вовсе, а тесты этого не покажут.
