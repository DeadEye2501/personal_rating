## Как гонял

Ломается **одна строка**, гоняется **один файл** тестов — тот, что сторож
сломанного, — правка откатывается немедленно. Драйвер (`/tmp/mut/batch.py`)
читает исходник, подменяет строку по номеру со сверкой образца, запускает
`pytest <файл> -q`, восстанавливает исходник в `finally`. После каждой пачки —
`git diff --stat`, пустой.

Питон — общий venv, без `pipenv`:
`C:/Users/deade/.virtualenvs/personal_rating-nun1_nuE/Scripts/python.exe -m pytest`.

Каждая молчаливая мутация проверена отдельно: на чистом коде тот же файл зелёный,
под мутацией зелёный тоже, и названо свойство, оставшееся без сторожа. Где
свойство оказалось ненаблюдаемым — так и записано.

Проверено пробой, не рассуждением:

```
already_shaped(квадрат 1000x1000, Kind.MUSIC) -> True
already_shaped(квадрат 1000x1000, Kind.MOVIE) -> False
crop_to_cover(квадрат, Kind.MOVIE)            -> 500x750
```

То есть при любой из этих семи поломок **обложка альбома, скачанная с Deezer,
ложится в хранилище афишей 500×750** — с обрезанными боками, — а весь набор
остаётся зелёным. Это ровно то, ради чего делался слайс 4.

`out[0] == out[1]`, а квадратность выхода обеспечивает **не пропорция обрезки, а
`SQUARE_SIZE`**: `crop_to_cover` ужимает до `size` независимо от того, что
вырезала `_centred_box`. Поставь `SQUARE_RATIO = 2/3` — картинка режется афишей
и **сплющивается** в квадрат, а тест зелёный. Второй сторож, «полоса по
центру», на этой подмене тоже проходит: обрезка остаётся симметричной, просто
уже.

Чем закрывается:

- по звену — тест, дающий загрузчику / привязке / `serve` карточку `Kind.MUSIC`
  с квадратной обложкой и требующий, чтобы в хранилище легло `out[0] == out[1]`
  (сегодня такого не делает ни один);
- по пропорции — проверка **содержимого**, а не размера: красная полоса шириной
  в десятую долю широкой картинки обязана в квадрате занять пятую, а при

`Izd-Vo "Mik"` — у обоих обрамление целиком состоит из слов, которые снимает

#### 19. Срок отката Deezer по частоте

**D03**, `deezer/client.py:33`: минута → сутки. `test_deezer.py`,
`test_backoff.py` — зелено.

Что источник взводится и что причина `RATE` — сторожится; **чем именно** — нет.
Сутки вместо минуты означали бы, что музыка молчит до завтра после одного
залпа, при том что замер показал: Deezer отпускает за секунды.

#### 20. Порядок «сначала тело, потом код» у Deezer

**D08**, `deezer/client.py:118`: разбор тела делается только при `200`.
`test_deezer.py` — зелено.

Это заявленное «всё содержание клиента»: `_taken` разбирает тело до кода.
Проверки на `200` с отказом внутри (D07 ловится) и на не-`200` с годным телом
есть, но обе выживают при перестановке — не хватает случая «не-`200` **и** отказ
в теле», где порядок и решает, какой из двух вердиктов увидит человек.

#### 21. Порядок перебора при поиске близкого написания

**E06**, `credits.py:169`: `order_by(id)` → `order_by(id.desc())`.
`test_credits.py` — зелено.

Докстринг называет это решением с ценой: «прилипнет к заведённой раньше, а не к
своей», — и именно это свойство не наблюдается. Закрывается: две подходящих
строки, ответ обязан быть первой по номеру.
