# План: книги и музыка, два новых типа содержимого

Спека — `docs/specs/2026-08-22-books-and-music.md`: там решения пользователя от
22.08.2026 дословно и границы обоих этапов. Разведка, из которой взяты все
адреса, — `docs/research/2026-08-21-books-tab.md`.

**Что делаем.** Переключатель типа складывается в иконки, разворачивается только
выбранная вкладка. Вкладок становится пять: к фильмам, сериалам и играм
добавляются книги и музыка. Оба новых типа работают целиком, кроме внешней
половины поиска — клиентов под них нет, и реестр источников об этом честно
говорит вместо того, чтобы молча уехать в TMDB.

**Чего не делаем.** Клиентов внешних источников, списков жанров, миграции, новых
полей карточки, оценок агрегаторов, трёхсторонней шкалы. Это второй этап,
отдельная спека.

## Общие условия

- **Порядок работы обычный:** слайс — одна задача, после каждой ревью отдельными
  агентами по измерению, чистка, коммит. Следующая задача начинается сразу.
- **Схема базы не трогается ни одной колонкой, миграций в плане нет.** `kind`,
  `role` и `genre.kind` везде `Text` без `CheckConstraint` — новое значение
  ложится строкой как есть.
- **Компоненты не проверяются прогоном** — решение 31.07.2026. Единственная
  проверка разметки и оформления: запустить окно и посмотреть. Где задача
  сводится к виду, красно-зелёного цикла нет, и это сказано прямо.
- **Цвет пишется только в палитру.** Литерал в любом другом файле оформления
  отклонит хук на записи.
- **Стиль блока — свой файл в `client/styles/`.** `<style>` внутри компонента
  запрещён.
- Прогон: `pipenv run pytest -q` и `cd client; npm test`.
- Живой запуск: `pipenv run python main.py`. Правка разметки без окна:
  `cd client; npm run dev`.

## Порядок задач и почему он такой

Переключатель идёт первым, на нынешних трёх вкладках. Так каждый слайс остаётся
показуемым: пять полноразмерных подписей в старой капсуле раздули бы её примерно
до шестисот пикселей, а вместе с ней — обе боковые зоны, и на минимальном окне
обрезался бы ряд кнопок. Цена обратного порядка — одно число, к которому во
второй задаче прибавляются две свёрнутые кнопки; это арифметика с проверкой
глазами, а не второй замер.

```python
async def test_a_book_is_searched_only_in_our_own_base(sessions, reference):
    """Внешние источники книг приедут вторым этапом. До тех пор внешняя половина

    Клиент подставлен отвечающий: пустая выдача обязана получиться оттого, что

    found = FakeSearch(Found([
        hit("1", "Дюна", source=Source.TMDB, kind=Kind.MOVIE),

    assert result.views == []
```

Чтобы этот тест мог упасть, двойник обязан повторять правило реестра. В
`tests/fakes.py` у `FakeSources` уже есть два таких повтора с объяснением «сервис
обязан слушаться реестра, и без этой ветки проверить его послушание было бы
нечем»; добавляется третий, и все три получают общий набор:

```python
    # Типы, у которых источников нет вовсе. Правило повторяется отсюда нарочно,
    # по тому же доводу, что и «у игр — никто»: само оно живёт в
    # `Sources.ROUTES`, а здесь проверяется послушание сервиса.
    NOBODY = frozenset({Kind.BOOK, Kind.MUSIC})

    def catalog_for(self, kind: Kind) -> list:
        return [] if kind in self.NOBODY else self._clients

    def people_for(self, kind: Kind):
        if kind is Kind.GAME or kind in self.NOBODY:
            return None
        return self._clients[0]

    def rating_sources(self, kind: Kind) -> list:
        if kind is Kind.GAME or kind in self.NOBODY:
            return []
        return self._clients
```

### Шаг 4. Таблица маршрутов вместо умолчаний

```python
class Route:
    """Кто отвечает за один тип содержимого. Клиенты названы именами полей
    `Sources`, а не объектами: таблица объявляется до того, как хоть один клиент
    поднят, и читать её должны в том числе тесты границы — без сети и без
    ключей."""

    catalogs: tuple[str, ...]
    people: str | None
    ratings: tuple[str, ...]


FILM_RATINGS = ("mdblist", "omdb", "kinopoisk")

ROUTES: dict[Kind, Route] = {
    Kind.MOVIE: Route(("tmdb",), "tmdb", FILM_RATINGS),
    Kind.SERIES: Route(("tmdb",), "tmdb", FILM_RATINGS),
    Kind.GAME: Route(("steam", "gog", "old_games"), None, ()),
    Kind.BOOK: Route((), None, ()),
    Kind.MUSIC: Route((), None, ()),
}
```

Методы становятся чтением таблицы:

```python
    def catalog_for(self, kind: Kind) -> list:
        """Порядок значим: он задаёт, чью выдачу человек увидит первой при
        равном числе кандидатов.

        У игр три равноправных источника, и покрытие даёт их сумма: Steam и GOG
        знают только то, что продаётся сегодня, old-games.ru закрывает ретро —
        «Дюны» нет ни в одной из витрин вовсе. У книг и музыки не спрашивают
        никого: клиентов под них нет, и выдача честно пуста."""
        return [getattr(self, name) for name in ROUTES[kind].catalogs]

    def people_for(self, kind: Kind):
        """Кто умеет искать по человеку. У игр — никто, и это замерено: Steam по
        разработчику отдаёт разметку витрины, GOG молча игнорирует параметр и
        возвращает весь каталог."""
        name = ROUTES[kind].people
        return getattr(self, name) if name else None

    def rating_sources(self, kind: Kind) -> list:
        """У игр оценки приходят вместе с карточкой, из Steam и GOG. У книг и
        музыки агрегаторов нет и не предвидится: Goodreads закрыл выдачу ключей
        в 2020, у LiveLib публичного API нет."""
        return [getattr(self, name) for name in ROUTES[kind].ratings]
```

**Умолчания нет ни у одного из трёх.** Обращение по типу, которого в таблице
нет, поднимает `KeyError` на месте — это и есть разница между «тип забыли» и
«тип молча уехал в TMDB».

Докстринг класса `Sources` — «Кто отвечает за какой тип содержимого» — остаётся
верным и никуда не переезжает.

```python
def strings_of(table: str, text: str) -> set[str]:

    start = text.index(f"const {table} = [")
    return set(re.findall(r"'(\w+)'", text[start:text.index("]", start)]))
```

и сама сверка читает им:


- [ ] **Шаг 6. Зелёное, живьём, карты, ревью, коммит**

Живьём: завести альбом с исполнителем и пятью треками, сохранить, открыть
заново — порядок тот же. Удалить карточку и убедиться, что треков не осталось.

## Чего этот план не делает намеренно

- **Не заводит миграции под справочник жанров.** Сеять нечего: списки у книг и
  музыки пусты до второго этапа. Ревизия в плане всё же есть, и она одна —
  `0003` под таблицу треков, задача 4. Миграции теперь наслаиваются, старые не
  трогаются: оговорка «пока в базе нет ничего, что жалко потерять» перестала
  выполняться.
- **Не трогает охранников `is not Kind.GAME`** в `service/loading.py`,
  `service/merging.py` и `service/relevance.py`. Раскладка названий по
  письменности, склейка изданий и отсев нерелевантного — свойства игровых витрин,
  и книгам с музыкой они не должны доставаться.
- **Не заводит лейбл и издательство.** Подпись роли `publisher` одна на всё
  приложение, и «Лейбл» у альбома потребовал бы подписи, зависящей от типа.
- **Не трогает `Facts.svelte` ради книг и кино.** Строка длительности
  скрывается сама, состав собирается по ролям с титрами. Треки альбома — своё
  место рядом с составом, и заводит его задача 4.
- **Не заводит трёхсторонней шкалы.** Оценка книги и альбома односторонняя, как у
  кино; колонки `visual`, `narrative`, `gameplay` остаются пустыми.
- **Не выдумывает ничего для пустой внешней выдачи.** Раздел «Поиск» работает как
  везде: своя половина плюс внешняя, и внешняя пуста, пока нет клиентов.
