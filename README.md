# Personal Rating

Десктопное приложение для Windows: свои оценки фильмам, сериалам, играм, книгам
и альбомам. Однопользовательское, база локальная, своего сервера нет.

## Что умеет

- **Ставить оценки.** Фильму, сериалу, книге и альбому — одну, игре три: визуал,
  нарратив, геймплей. Ступеней десять или пять — переключает `SCALE_X2` в
  настройках; смена пересчитывает уже выставленное и необратима.
- **Писать свои рецензии** к любой карточке.
- **Хранить и показывать без интернета.** Фильтры по жанрам, тегам и оценке,
  сортировка, гистограмма по разделу. Без сети нельзя только одно — найти
  готовую карточку во внешней базе.
- **Вести список запланированного** — «Хочу посмотреть», «Хочу поиграть»,
  «Хочу прочитать», «Хочу послушать».
- **Заводить карточки руками** — целиком или привязав к внешней базе вставленной
  ссылкой.
- **Показывать оценки агрегаторов** у фильмов и сериалов — IMDb, Rotten
  Tomatoes, Metacritic, Кинопоиск, — если ключи заполнены. Игре чужая оценка
  приезжает вместе с карточкой из самого магазина: у Steam это Metacritic, у
  GOG — своя. У книг и музыки агрегаторов нет вовсе.

## Откуда данные

| Тип | Источник | Ключ |
|---|---|---|
| Фильмы и сериалы | TMDB | нужен |
| Игры | Steam, GOG, old-games.ru | не нужен |
| Книги | Google Books | нужен |
| Музыка | Deezer | не нужен |
| Оценки агрегаторов | MDBList, OMDb, два зеркала Кинопоиска | нужен, необязательно |
| Обложки книг, запасные | FantLab | не нужен |

Google Books принимает и второй ключ, необязательный: суточная тысяча считается
на проект, и ключ от другого аккаунта продлевает день.

Единица учёта музыки — альбом, а не трек и не исполнитель; треки показываются
списком в карточке.

Одна игра продаётся в нескольких магазинах, и выдача сводит её в одну строку: по
названию, слагу и второму названию, с проверкой года. Что не свелось, убирает
человек — приложение помнит это навсегда. Слово «удалённые» в строке поиска
показывает убранное и даёт вернуть.

## Запуск из исходников

Нужны Python 3.13, Node 22 и npm 10.

```powershell
pipenv install --dev
cd client; npm ci; npm run build; cd ..
pipenv run python main.py
```

Страницу собирает Vite, и без `npm run build` окно откроется пустым: готовое
дерево `client/dist` в репозиторий не входит.

Папку данных, файл настроек и схему базы приложение заводит само при первом
запуске. Ключи вписываются руками в созданный `.env`, после чего нужен
перезапуск. Без ключей работают игры, музыка и вся своя библиотека.

## Проверки

```powershell
pipenv run pytest -q      # без сети и без живых ключей
pipenv run ruff check .
cd client; npm test
```

Ответы источников записаны в `tests/fixtures/` — десять папок, по одной на
источник.

## Устройство

Три папки верхнего уровня:

- `backend/` — база, источники, вся логика. Работает в своём потоке.
- `bridge/` — окно, поток бэкенда и семь доменов моста между страницей и им.
- `client/` — страница: Svelte 5, сборка Vite. Ни строки Python.

Интерфейс — веб-страница внутри окна на pywebview, рисует её системный WebView2.
Граница слоёв совпадает с границей потоков: в потоке интерфейса нет ни одного
обращения к сети или диску.

## Сборка

Сначала страница, потом exe.

```powershell
cd client; npm run build; cd ..

pipenv run pyinstaller --onefile --noconsole `
  --icon="Personal Rating.ico" --name "Personal Rating" `
  --add-data "client/dist;client/dist" `
  --add-data "migrations;migrations" `
  --add-data "alembic.ini;." `
  --add-data ".env.example;." `
  --add-data "Personal Rating.ico;." `
  --hidden-import aiosqlite `
  --hidden-import logging.config `
  main.py

cp "dist/Personal Rating.exe" "./Personal Rating.exe"
rm -rf build/ dist/ __pycache__/ "Personal Rating.spec"
```

Что зачем: `client/dist` — страница, без неё окно пустое; `migrations` с
`alembic.ini` — схема базы; `.env.example` — из него заводится файл настроек;
`Personal Rating.ico` — иконка окна; `aiosqlite` и `logging.config` PyInstaller
не находит сам, потому что первый подключается по имени, а второй нужен только
`migrations/env.py`, который alembic грузит на лету.

Готовый `.exe` в репозиторий не попадает — он уезжает вложением в релиз.
